# Create staging layer scripts

## Goal
Prepare staging tables for ETL processing.

## Description
Create scripts in `src/sql/04_staging/` to load source data into staging before warehouse transformations.

## Deliverables
- Staging table scripts
- Basic load scripts or insert-select patterns
- Notes on which source tables feed each staging table

## Done when
- [ ] Staging scripts are created
- [ ] Source-to-staging flow is understandable
- [ ] Scripts are organized in the folder
- [ ] Changes are committed
