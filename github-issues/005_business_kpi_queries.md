# Build business KPI queries

## Goal
Create SQL queries that answer the main reporting questions.

## Description
Write SQL scripts for KPIs such as total sales, orders, average order value, top customers, top products, and territory performance.

## Deliverables
- KPI query file in `src/sql/02_reporting_queries/`
- Queries for at least 6 business metrics
- Clear naming and comments

## Done when
- [ ] KPI queries are created
- [ ] Outputs are checked for reasonableness
- [ ] Scripts are organized clearly
- [ ] Changes are committed
