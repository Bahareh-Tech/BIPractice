# GitHub Issues Backlog

This folder contains ready-to-use issue drafts for the AdventureWorks BI project.

## How to use
1. Open GitHub repository Issues tab.
2. Create a new issue.
3. Copy the content from one file in this folder.
4. Paste it into the issue body.
5. Add labels if needed.
6. Create a branch for that issue.
