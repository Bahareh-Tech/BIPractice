# AdventureWorks BI Project

A portfolio-style BI project using SQL Server and the AdventureWorks database.

## Goal
Build a small end-to-end BI solution that simulates real junior / associate BI developer work:

- explore source tables in AdventureWorks
- write reporting and analysis SQL queries
- create reusable SQL objects
- design a small data warehouse
- build ETL in SQL Server
- create Power BI reports
- manage work with a simple GitHub workflow

## Project Phases
1. SQL refresh and project setup
2. Reporting SQL and reusable objects
3. Data warehouse design
4. ETL implementation in SQL Server
5. Power BI reporting
6. Final polish and portfolio readiness

## Suggested Workflow
For each task:
1. Create an issue from `github-issues/`
2. Create a branch
3. Do the work
4. Open a PR
5. Merge to `main`

## Repository Structure
- `src/docs/` - project notes and design documents
- `src/sql/` - SQL scripts by phase
- `src/powerbi/` - Power BI assets and screenshots
- `src/diagrams/` - architecture and model diagrams
- `github-issues/` - ready-to-use issue draft templates

## First Tasks
- document AdventureWorks source tables for sales reporting
- create SQL warm-up query pack
- build reporting views
- design the star schema
- create ETL scripts
- build Power BI dashboard

## Notes
Keep the focus on BI skills first. GitHub and Copilot should support the work, not become the main topic.
